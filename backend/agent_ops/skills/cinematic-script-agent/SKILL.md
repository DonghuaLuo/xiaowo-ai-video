# 片段影视化剧本

只处理当前分集会话中明确的 `prompt.storyboard` 节点。目标 `nodeId` 必须来自结构化快捷任务、画布选中目标或用户明确指定；多个可能目标时先澄清，不默认选择第一条工作链。用户反馈若针对已生成剧本，应保留本会话已经确定的创作要求并修订同一目标。

## 1. 读取与确定创作方案

资料包返回当前片段的 `narrativeMode`。当前只开放 `drama`（剧情演绎）；未开放模式由后端拒绝，不得自行按旁白讲述交付。项目模式是默认值，片段卡模式是本任务的有效选择；它与“创作策略”分别判断。

先调用 `get_cinematic_script_context(part="generation_bundle")`，一次取得本次片段原文、前段原文与紧邻上一链剧本、`entryAnchorText`、当前已保存剧本、策略正文、用户要求、叙事模式和 `inputDigest`。如果当前工具定义没有 `generation_bundle`，或调用返回 `invalid_part`，说明运行时工具与本 Skill 版本不一致：停止并报告，不改用旧分项读取来冒充本流程已执行。片段原文是本轮创作范围；`entryAnchorText` 只提示前段结束时的现场，不授权补演边界外事件；有紧邻上一链剧本时以其正式终态为准。按 `defaultScriptTemplateId` 选取资料包中对应策略并遵循其 `prompt`；结构化任务指定的策略优先。修订时读当前稿并保留本轮反馈未否定的有效人工剧情内容；旧稿中的编辑层字卡、人物介绍卡或其他已退出本合同的装饰要求不得复制到新稿，只有故事场景里真实存在的载体文字可保留。已成功读取资料包但具体字段缺项或上下文确有歧义时，才按同版 `part` 补读；资产身份确有缺口时再按目标查询，不加载完整资产目录。缺少片段原文或策略不可用时说明阻碍；较早的有效要求缺失时用 `get_conversation_history` 查询本会话。输入变化时重新读取整份资料包，核对新稿与新约束后再提交，不能只替换摘要。

用户明确要求参考、比较或结合以前的修改版本时，先调用 `list_workflow_node_versions` 确认当前节点的版本编号、来源及 ID，再按需用 `read_workflow_node_version` 读取所指版本的剧本正文与当时的修改要求。修改记录也可能包含生成前的原文或策略编辑；用户说“第一版剧本”时，应对照来源和正文预览找第一份实际剧本，不能直接把第一条空草稿当作剧本。含义不明时先澄清。把旧稿作为比较与借鉴资料，仍以当前原文事实、本轮用户要求和当前输入版本为提交依据。普通创作或只修改当前稿时不加载所有历史版本；查询历史不等于恢复或提交旧稿。

**通过条件：**目标、原文范围、策略、用户本轮与历次有效约束及输入版本明确。

## 2. 恢复现场并写完整片段

剧本阶段不读取或应用镜头节奏。只确定有依据的行动、声音、书面讨论的发言选择及其声源；书面信息可改编为简洁口语，但保留观点、问答关系与原意。每镜播放时长和倍速由后续分镜阶段计算。

匿名弹幕或群聊的“群众”是多个彼此独立的临时发言者，不是“群众男声”和“群众女声”两个可轮流代读所有消息的共用声源。书面消息默认留在原载体：先按本段因果找出观众必须听懂的观点变化、问答转折与人物反应，再比较候选发言，删掉去除后不改变理解或反应的配音；其余消息快速滚动。**先决定最少需要听见哪些发言，再给入选者分配身份和声别**，不能为了展示多人、多声线或男女搭配扩大入选集合。对入选发言，按原有署名、账号或可辨的问答身份区分说话者；匿名但来自不同人的发言可用“观众甲、乙、丙、丁……”等临时名称，人数由实际入选的独立发言者决定，不固定为两人或四人。同一人跨句复用声源，不同人即使同为男声或女声也不得合并；不能把原文明确的多人讨论压成一男一女对话。只剩两名有依据的发言者时，按两人对话表达，不称作群众讨论；不为凑人数编造原文没有的发言。原文有署名或已绑定身份的发言仍用原声源。

本 Skill 的“原文对白原话”指故事中实际说出口的语言。群聊、弹幕、短信等原本是书面信息；当它们构成观众需要跟随的讨论时，剧情演绎可将选中的发言改编为**有原载体来源的多声部讨论配音**，不要求观众逐字读屏。配音是给观众的叙事声音，角色是否听到仍以故事来源为准。画面保留屏幕、消息变化和人物反应；屏幕字形不必逐字准确，**但这不是把书面消息改成配音的理由**。若载体主题、可见变化及人物反应已经交付某条消息的作用，就让该消息留在画面信息流中；只有缺少它的声音会使关键观点、问答转折或反应失去依据时才入选。入选发言的关键意思、归属和问答顺序必须一致。

入选发言写成可完整说完的对白行，保留信息、说话者、应答关系与原有确定程度；每个独立发言者有自己的临时声音身份，同一说话者在片段内沿用同一声线，不同说话者的声音可辨。为已入选的匿名观众逐人选定并在发声标签写明配音声别；有足够入选者时可让不同男性声线与不同女性声线参与讨论，声别多样性不参与发言取舍。同一人的声别跨句保持，声别不能充当说话者身份或原著性别事实。背景消息只作为有来源的信息流，不安排逐字读屏或无意义配音。写完剧本后逐句撤去由书面消息改成的配音：若去掉该声音后，现有画面、其他发言与人物反应仍交付同一变化，就把它还原为快速文字流；再核对保留的完整发言与屏幕更新、人物操作或反应在同镜发生。不要把同一讨论拆成大量先看空屏、后听声音的镜头，也不要用单一旁白代替多人讨论。


**先做轻量叙事契约，再写剧本；正常短片段在同一轮创作中完成两步。**依原文的连续事件边界，在工作稿中为每段记下：来源依据、时间方向与事实确定程度、观众必须获得的因果或信息、知道该信息的人、拟用的可见／可听／可读载体及进入／退出关系。区分普通现场演绎、顺时压缩、过程蒙太奇、角色回忆、想象、梦、内心活动、人物讲述、未证实转述、暧昧及其他实际存在的表达；一段可以组合多类，不按句子或固定时长分段。当前现场写连续表演；顺时压缩与蒙太奇挑少量代表性变化；回忆明确记忆主体和返回触发；梦、想象与内心保留主观归属，讲述与转述保留来源和事实确定程度，暧昧保留人物互动依据。依据这份契约按原文因果写出完整剧本，统一检查段落交界和人物状态。契约不写进剧本正文；发现来源或声画无法匹配时，只改对应段落并重新核对关联内容。

剧情演绎以角色行动、互动、对白和声画结果推进。小说第三人称叙述是待改编的故事信息，不是默认旁白。没有多人互动时，也可以用具有目标、过程和结果的单人行动推进；不为制造对话添加无来源的人物或交流。连续缺少人物交互的概述优先压缩为少量有因果增量的变化；角色回忆、讲述或自述须有明确的角色视角，让声音与相关行动或画面同步成立。不把一段内容写成先播无信息画面、后来才补说话。每段叙述先提炼本片段必须让观众理解的因果，再决定呈现方式；叙述里的背景说明和形容不要求逐句配音或逐项展示。

本项目以人物可表演的发声、交锋和反应带动常规场景：有原文对白先让它承担镜头推进；没有直接对白但有明确人物知识与交流依据时，可将间接转述改成简洁、自然且不超出人物所知的对白或有归属自述。不要凭空创造对话对象、身份、结论或长篇解释。只有景物描写、重复的工作状态或背景概述时，把它并入正在发生的人物交流或一次关键变化，快速交代即可；不把小说描写量转成连续无人声、无新信息的长画面。静默场面仅在一个动作、结果或揭示本身必须让观众看见时保留，且不重复前链已见状态。

对**没有当前人物互动的旧事、传播过程或快速概述**，先决定观众看完必须知道的起因、变化和结果，再选择代表性画面与入出点；原文每出现一个时间数字、说法或判断，并不自动产生一句声音。若确需讲述，优先有知识来源的角色视角；没有合法角色声源时，只用最短客观发声交付观众无法从画面推知、又影响本段理解的时间或来源。非关键的精确间隔可在制作说明中保持原文事实而不强制口播，也不能把它误写成屏幕上的真实字面。先完成这一段的声画组织，再写相邻现场，不用旁白逐项复述概述句。

沿原文事件先后走到片段起点，确定当时的时间、内外空间、在场人物、位置姿态、正在做的事与关键道具状态；使用最近一次变化后的状态接起剧本。当前片段没有重述地点或持物时，先核对紧邻上一段已保存剧本是否已明确建立且连续到本段；没有切场证据就承接该状态。开场只交代原文或连续剧本可确认且支撑表演的状态，未知背景保持开放。依选定策略写完片段中的行动、对话、心理、信息变化与结局；人物只根据当时已获得的信息行动。位置、手中物及道具每次变化都成为下一动作的起点。

- 进入另一内外空间时在对应动作处换场；场景标题写“内景或外景·地点·时间”。原文和连续的前段剧本均未交代的项明确写未交代，不凭空指定。
- 新增人物对白须符合当场的说话动机、人物已知信息及戏剧关系，并承担动作、反应或原有对白尚未交付的必要信息；不能把叙述者的感叹或总结换一个角色说出来，借此制造看似有互动的剧情。观众已能从可见结果和人物反应理解时，让人物继续行动或沉默。未给出的日夜、天气及具体时段也不能为填满场次标题而推定。
- 原文表达某事的价值、希望、重量或类似比喻时，先保留其叙事作用；不能把抽象评价改成来源没有给出的具体持续时长、次数、数量或过去经历。
- 原文只给出复数群体或泛称、没有明确人数时，保持开放数量；动作和结尾状态可写已入画的人物关系，不把它改写为“只剩几人”等确定总数，也不以画面暂未显示的成员已不存在作推断。
- 先区分当前现场行动、人物回忆、媒介画面与概述背景，再安排场次。场次标题只表示当前现场的空间变化。回忆、录屏、直播等按原文出现的位置嵌入当前场次，用“回忆画面”“直播画面”等来源标记；其中出现的地点不另立独立内外景场次。背景中提到的早先行动不前置补演成剧本开场。只有原文叙事确实转到另一处当前行动时才换场；若该处的室内外或具体空间未交代，选择能执行原有动作的最小、普通空间作调度，不写“内外景未交代”一类占位场次头，也不将选用的空间冒充原文已确认的剧情事实。没有来源的播放量、排名、倒计时等可见指标不用于替代原文的抽象传播或状态描述。
- 叙述里“以前常见”“有人都知道”“大家推测”等回顾或群体认知，先保留其时间和知识归属：没有当前查看旧记录、播放回放或人物得知的来源，就不写成眼前新出现的屏幕内容，也不写成主角已经确认的内心结论。若此类背景不是本段因果必需，可以让当前人物反应与已有载体暗示，不为完整复述背景加新画面或发声。
- 对影响理解的画面段落，在相关动作处写清来源视角、事实确定程度、时间方向和进入／返回现场的触发：按时间顺序跳过数日或数年是顺时压缩，过程蒙太奇保留有因果增量的步骤，只有角色在当下回想才是角色回忆；梦、想象、内心与未证实转述不能拍成已证实的现场事实，人物讲述要有讲述者，暧昧要有互动依据，录屏等媒介画面保留载体，并行行动写清同时关系。可用简短的段落提示及必要的入出动作，不把它们另立为当前现场的场次。普通连续戏不添加提示，剧本不为类型编排图片效果。
- 原文若以概述或短句快速跨过数次变化，先判断每次变化对本片段的叙事职责，再选少量可辨的行动与结果组织快节奏段落；来源只交代起点和结果、没有描述中间过程时，用跳切或代表性落点交付结果，不自行补演完整的渐变过程、等待及每一步临场反应。不要仅为把每项结果拍全，就把概述扩写成多个等重、长时间观察的完整现场，也不默认给每次变化加一句反应对白。原文明确要求停留的转折仍给足可见反应；压缩节奏不能省略关键因果或改变时间方向。
- 环境与动作写成简洁、可见、可执行的短段；台词和声音另起行，用“角色（对白）：”“角色（内心声）：”或“旁白：”标明性质。设备声音也保留对白标记，如“角色（对白·设备声）：”，使后续分镜能区分真实发声与屏幕文字；画面文字注明载体。原文间接转述的发言若承担必要信息，应在本环节依原意整理为该人物可说出的明确对白，保留人称、条件、因果和知识范围，不增加结论；原文已有逐字对白仍按策略的原话要求保留。不能只在动作说明里写“他说明／她解释”而让关键信息没有实际发声。没有的表达类型不必添加。
- 对每段叙述、心理、过去决定、意图与判断，先辨认观众必须理解的具体信息及其知识归属，再决定由动作结果、人物互动、已有对白、真实载体文字或声音承担。可见的过程和结果由表演交付，不复述为旁白；明确的主观判断若不能从画面可靠理解，则用符合人物知识范围的自然对白、简短内心声，或仅属于作者视角时的简短旁白补足。不能只写“看出／明白”而没有观众可接收的依据，也不能把每句心理原文整段自动改成第一人称内心声。确需保留的原话遵守用户要求与有效策略，但先判断它是否必须出声。没有必要声音时不强加声音。
- 媒介讨论先保留画面载体：在对应动作段写出群聊气泡、直播弹幕或系统界面的存在、刷新方向和人物观看关系；这些画内文字只需呈现信息正在发生，不要求图像模型把字逐字写对。观众必须听懂的讨论另写“姓名（对白·群聊配音）：”“观众甲（对白·弹幕配音，男声）：”“观众乙（对白·弹幕配音，女声）：”等完整发声行，原有署名者保持归属；不同临时观众各有身份和声线，同一观众复用自己的声线与声别。男女声可以交错选角，但不把选角当作原著性别事实，也不把同声别的不同观众合为一人。配音只给观众听，故事角色是否听到须有来源依据。系统消息若需要发声，明确是系统播报或角色转述，不冒充群众讨论。画内信息与声音在同镜配合，不生成逐字读屏任务。
- 同一媒介内有多条发言时，按本段因果选出需要观众听见的问答、争论或转折，入选句子必须由对应说话者完整说完且顺序可辨；其余只作为屏幕上的滚动文字和人物反应，不安排冗长无声停留。只有字面本身是谜底、编号、指令等必要线索时，才另外用“画面文字（……清楚可读）：”要求逐字阅读；这属于例外，不作为群聊、弹幕和系统界面的默认路径。
- 复核整段声音密度和镜头职责：连续群众讨论可以承担剧情推进，但每句须与当时可见的媒介变化、人物行动或有效反应同步；不能把一串发言拆成先看空屏再说话的碎镜，也不能用单一旁白念完多人讨论。若发声过密且难与有效画面对应，回到剧本选择代表性讨论和因果；镜长与语速由分镜按项目节奏计算，不靠长时间读屏或垃圾镜头解决。

**通过条件：**剧本从当前现场自然开始，完整演完片段并可由演员、导演执行；创作策略只改变表达方式，不覆盖来源事实。

## 3. 同轮自检与定点返工

完成剧本后，在本轮创作中依次核对以下三关；不另写交付清单、不增加模型任务。用户给出反馈时只重写受影响段落，再复核与它相连的事实、声音和出入状态。

1. **事实粒度**：逐段从来源对照人物、时空、人数、因果、物件状态和结果，再从剧本反查新增的具体细节。压缩多条媒介信息后，再单独核对原文中不属于消息正文的人物身份、关系、已发生的状态变化和后续伏笔是否仍可由观众获知；删去逐条读屏不等于删去关键故事事实。原文给出疾病、冲突或情绪，只授权表达该状态；不能靠常识推断出未写明的具体症状、损伤、次数、具体时刻或额外事件。允许中性的表演和衔接动作，但观众不能由它们误以为来源确定了新的事实。开场接前段最近一次已确立的状态，末尾交出本段实际达到的状态；回忆、想象、转述和媒介画面不能冒充客观现场。原文直接对白及来源明确的画面文字按有效策略保留原意、顺序和归属。
2. **声音与画面**：先只看剧本中观众实际能看见、听见、读到什么，确认关键目标、阻碍、行动和结果可理解；场次标题、段落说明及作者备注不算观众已获信息。已有对白按人物当场动机说出；新增对白不能借角色之口念作者总结。对每句新增旁白和内心声做删声检查：若对应信息已由行动、反应、对白或场景载体交付，删去；若只是原文提到了却不影响本段理解，也不逐项口播。角色内心声须属于其知识与主观视角，并配当前可见表演或主观画面。可选内心声或旁白只保留观众必须听懂的必要信息，不复述已由声画交付的事实；再从整段检查客观说明声音是否取代人物行动与结果，不按旁白条数机械判定。镜头阶段再按项目节奏核算发声时长；不要为了规避时长把同一信息拆成多段无独立观看任务的声音。关键的精确时间、背景或作者视角信息若仍无法合法交付，才用有依据的短发声补缺；不要为每个原文时间标记各写一句旁白，也不能把真正必要的信息只留在制作说明里。声音与其承载的画面在同一观看过程成立，不写先播空画面、后来才补说话。原文明示的对白和必要发声不能为了减少旁白而删掉。
3. **速度与可拍性**：逐段核对场次、动作和转场是否可执行；快述只保留起点、关键变化和结果，不把几句概述扩成多个等重长场。重要反应有时间辨认；无信息的等待、反复情绪和过渡删去。确有时间、身份或数量精度要求时，选择最少且合法的声画载体，不凭空制造设备文字，也不因难拍就添加编辑层字卡。原文和连续上下文没有的日夜、天气、具体病程保持未交代。

三关任一不通过就修正正文并再核对应项。特别反查原文中的机会差异、人物关系、身份／状态改变和未证实判断：在动作说明中写“某人回复说了什么”“大家知道什么”不等于观众已经获得该信息。媒介讨论若决定剧情，就让选中的完整发言由明确声源说出，屏幕同时显示对应信息流；快速滚过的文字只交代来源和氛围。修正正文后提交，不靠额外清单掩盖交付缺口。

## 4. 提交与简报
调用 `submit_cinematic_script_result`，提交目标 `episodeId`、`nodeId`、当前 `scriptTemplateId`、读取所得 `inputDigest` 和 `cinematicStoryText`。只有本轮明确要求逐项核对交付证据时，才在同次提交附 `deliveryContract`；它不作为默认生成的另一份长草稿。工具在后端检查输入版本和目标节点，保存并回读。失败时按 `errors[].path/code/repairAction` 定点修订；输入过期先刷新；权限或写入状态不明则停止并说明，不能盲目重提。返回 `committed` 和可信 `commitReceipt` 后，调用 `publish_task_report` 提交几行结论：目标片段、使用的策略、完成了什么以及有无用户需处理的问题。只依据回执声明已落库，不输出 Skill、原文全文、工具日志或自检过程。报告成功后停止。

读取资料后若输入变化，提交会返回 `stale_context` 及 `requiredParts`。重新读取 `generation_bundle`，核对并修订正文；不能只换摘要重提交旧稿。旧的分项读取与 `submission_state` 只供兼容任务使用，不能用它们代替本轮完整资料包。

若用户只是讨论写法或未指定目标，先回答或澄清，不写节点。
