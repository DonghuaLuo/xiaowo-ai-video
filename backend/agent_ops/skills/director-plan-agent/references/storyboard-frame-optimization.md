# 起始画面字段专项优化

这是分镜智能体在完整镜头草稿完成常规可绘制质量检查后、正式预检前自动执行的图片供应商拒绝风险审查；只针对有风险的 `storyboardFrame` 措辞进行等义优化，无需用户逐镜发起。镜数、动作、声音与时长不在此流程中重写。剧本和原文是事实依据，不是要一起送给图片模型的画面提示。

常规可绘制质量检查在进入本专项前完成：起始画格可冻结，人数、站位、持物、资产身份、事实确定程度、统一项目画风及场景文字来源都正确。专项不得以“安全”为由改变这些已确认的事实。

1. **定位风险**：仅检查 `storyboardFrame` 中可能触发当前图片模型拒绝的事件称谓、刺激性细节和直接呈现要求；结合已复现的供应商拒绝记录判断，不把单个词当成所有模型的通用禁词。
2. **等义改写**：只在有风险的镜头，用克制、可见的姿态、空间关系和人物反应表达同一画面作用。镜头人数、物件归属、关键结果和事实确定程度不变；不改写剧本、声音、执行字段或其他镜头。
3. **复核与报告**：重新核对起始可见资产、相邻镜头起止状态及画面作用。不能等义表达时报告镜号和原因，不通过删除关键人物或因果来求出图。

供应商拒绝时，开发验收侧先查实际请求、参考图、错误码和拒绝阶段。只有确认问题定位到起始画面措辞，才用画面字段补丁修正；再次拒绝要重新检查输入边界与参考图，不循环替换同义词。当前智能体的职责仅是字段优化与提交，不执行图片请求。
