# 导演规则索引

本目录是分镜脚本按需读取的场面导演规则资料库。规则按戏剧功能分类，但正文要体现导演出发点、戏剧判断和镜头方法。它只回答“这段内容该怎么拍”，不改写剧情事实，不定义输出字段，不绑定任何小说、场景、角色、资产、故事版模板或视频模型语法。

使用原则：
1. 先理解可拍摄内容的主要戏剧功能，再判断最适合的场面导演规则。
2. 只选择 1 个导演规则模板。分镜脚本生成时只读取当前选中的这个规则全文。
3. 规则中的例子只解释导演方法，实际选择以当前剧情的戏剧功能为准。
4. 规则只能帮助表达当前可拍摄内容中已经存在的情绪、冲突、动作、信息和空间关系。
5. 规则只提供拍摄视角、戏剧判断、镜头方法、画面方法、执行方法和声音方法；资产绑定、分镜图绘制、供应商提示词适配、输出字段和质量验收分别由对应环节的主提示词和程序契约负责。

模板结构：
- 规则定位：说明这条规则解决哪类拍摄问题。
- 导演出发点：说明这类戏在导演眼里真正要拍什么。
- 戏剧判断：说明镜头应优先抓住哪种冲突、关系、情绪、信息或变化。
- 镜头方法：说明如何建立、推进、转折和收束。
- 画面方法：说明景别、机位、构图、站位、表情和道具关系。
- 执行方法：说明运镜、动作变化、节奏和停顿。
- 声音方法：说明声音如何服务这类戏的导演表达。

建议入口：
- `principles.md`：供维护者参考的通用镜头设计原则，不参与场面规则推荐，也不自动加入生成请求。
- `quality-checklist.md`：供维护者参考的质量自检清单，不参与场面规则推荐，也不自动加入生成请求；当前生成方法与质量检查以业务主提示词为准。
- `dialogue_power`：对话与信息博弈。
- `action_impact`：动作与冲击。
- `suspense_presence`：悬疑与压迫出场。
- `intimacy_emotion`：亲密与内心情绪。
- `reveal_subjective`：揭示与主观感知。
- `motion_transition`：运动与转场。
- `environment_symbol`：环境与物件象征。
- `scale_montage`：群像与规模蒙太奇。
- `character_entrance`：人物登场与身份压场。
- `transformation_power`：变化与能力显现。
